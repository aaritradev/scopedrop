## 📖 Overview

ScopeDrop helps freelancers and agencies analyze client requirements using AI.

Instead of reading long emails or project briefs manually, users can submit client requirements and receive a structured report that includes project scope, risks, pricing guidance, missing requirements, negotiation points, and proposal recommendations.

The goal is to reduce misunderstandings, improve project estimation, and help freelancers make informed decisions before accepting a project.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/scopedrop.git
```

Install dependencies

```bash
npm install
```

Create an environment file

```env
DATABASE_URL=

NEXTAUTH_SECRET=

GOOGLE_CLIENT_ID=

GOOGLE_CLIENT_SECRET=

GEMINI_API_KEY=
```

Run the development server

```bash
npm run dev
```
